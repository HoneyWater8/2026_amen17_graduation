참고 레포에서 **페이지뷰·UV를 아예 수집하지 못한 것**이 아쉬웠던 지점이라, 이번에는 행사 9일 전(2026-09-11)에 미리 붙였습니다.

| | Vercel Web Analytics | Google Analytics 4 |
|---|---|---|
| 맡는 것 | 방문자 · 페이지뷰 · 유입 경로 · 기기 | 봉투 열기 · 섹션 도달 · 영상 재생 · 공유 · 사진 확대 |
| 상태 | 2026-09-11 활성화 완료 | 측정 ID `G-P7PXPF9CWM`, `FE/index.html`의 구글 표준 스니펫으로 초기화 |
| 쿠키 | 없음 | 사용 |
| 보존 | **1개월** (Hobby) | 14개월 |

**Why 둘 다인가:** Hobby 플랜은 **커스텀 이벤트를 지원하지 않고 리포팅 윈도우가 1개월**입니다(이벤트 한도 5만/월은 이 규모에 충분). "봉투를 열었나 / 어디까지 봤나"는 Vercel로 볼 수 없어 GA4가 그 구멍을 메웁니다. Pro 트라이얼로도 되지만 종료 후 과금되고 플랜을 올렸다 내려야 합니다.

## 운영 통계 회수 — 2026-10-24 완료 (GA4 기준)

Vercel 보존 기한(10월 중순)이 지나 **사용자 지시로 Vercel은 확인하지 않고 GA4만으로** 2026-09-11 ~ 10-22를 정리했습니다. 결과는 `README.md` 「운영 통계」와 `docs/ga4-*.png`, 경위는 [작업로그](../worklog/2026-10-24-ga4-operating-stats.md)에 있습니다. GA4 데이터는 14개월 보존이라 2027-11 무렵까지 다시 볼 수 있습니다.

- GA4 속성 경로: 계정 `SuHeonChoi` / 속성 `2026_amen17_graduation` / URL 조각 `a407497182p553594064`
- **맞춤 측정기준 2개 (2026-10-25 등록)** — `section`·`video`, 둘 다 이벤트 범위·매개변수명과 같은 이름. 소급되지 않아 **2026-10-25 이후 방문분만** 섹션별·영상별로 나뉩니다. 행사 기간 통계와 섞어 비교하지 않습니다. `share_copy`의 `ok`는 등록하지 않았습니다. 경위는 [작업로그](../worklog/2026-10-25-ga4-custom-dimensions.md).
- 링크 공개일은 사용자 기억으로 **2026-09-26**(기록 없음). 9/20 예배 당일 0건은 링크 공개 전이라 장애가 아닙니다.
- 내부 트래픽 필터 없음 — 개발 접속(특히 9/11 ~ 9/12)이 통계에 섞여 있습니다.

**다음 행사에 적용할 것:** 배포 전에 맞춤 측정기준과 내부 트래픽 필터를 먼저 등록하고, Vercel Hobby를 쓴다면 행사 후 한 달 안에 통계를 회수합니다.

**캡처 방법:** GA4는 Playwright가 띄운 브라우저에서 구글 로그인이 막힙니다. 별도 프로필의 일반 Chrome을 `--remote-debugging-port`로 띄워 사용자가 로그인하고 `connectOverCDP`로 붙습니다. 레포가 공개라 이메일이 보이는 상단 바는 넣지 않고 카드·표만 자릅니다. 보고서 기간은 URL의 `params=_u.date00%3DYYYYMMDD%26_u.date01%3DYYYYMMDD`로 지정됩니다.

## 확인·디버깅

- **`?ga_debug=1`** 로 접속하면 `config`에 `debug_mode`가 실려 GA4 **DebugView**에 실시간으로 찍힙니다. 재배포 없이 켜고 끌 수 있습니다.
- 전송 자체는 개발자 도구 Network에서 `collect?v=2` 요청으로 확인합니다. **`204 No Content` + `tid`가 측정 ID와 일치**하면 브라우저 쪽은 정상입니다.
- 스트림 상세의 "데이터 수집이 활성화되어 있지 않습니다" 배너는 **48시간 기준**이라, 붙인 직후 떠 있어도 이상이 아닙니다. 신규 속성은 첫 데이터가 보고서에 반영되기까지 지연이 있습니다.

## How to apply

- 이벤트를 추가할 때는 `FE/src/utils/analytics.ts`의 `track(name, params, once)`를 씁니다. `once=true`면 같은 키로 한 번만 보냅니다(스크롤 왕복 대비).
- **`VITE_GA_ID`는 현재 코드에서 사용하지 않습니다.** 환경 변수 유무와 관계없이 `FE/index.html`의 스니펫이 초기화합니다. ID를 바꾸려면 스크립트 URL과 `gtag('config', ...)`를 함께 변경합니다.
- 초기 도입 시 환경 변수에 ID를 등록했지만, 모듈로 동적 로드하던 방식의 전송 문제 때문에 2026-09-11 표준 HTML 스니펫으로 교체했습니다. 이전 환경 변수 설명을 근거로 초기화 방식을 되돌리지 않습니다.
