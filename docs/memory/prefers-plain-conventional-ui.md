디자인 판단이 갈릴 때 **관습적이고 담백한 쪽**을 고릅니다. 컨셉 일관성을 위해 장식을 더하는 방향은 지금까지 전부 되돌려졌습니다.

2026-09-07 ~ 09-08 사이 확인된 다섯 사례:

| 내가 고른 것 | 내 근거 | 결과 |
|---|---|---|
| 왁스 씰이 위에서 눌러 찍히는 진입 연출 | "봉인" 은유가 컨셉과 맞물림 | ❌ 제거 — 씰은 봉투에 이미 붙어 있는 물건 |
| 바텀시트 `radius: 0` | 핸드오프 토큰이 "전부 각진 사각형" | ❌ 18px 라운딩 |
| 토스트 `radius: 0` | 위와 같음 | ❌ 알약 형태 |
| 시트 상단 금박 이중선 | Frame의 장식 언어 재사용 | ❌ 제거 |
| `아래로 넘겨보세요` | 봉투 안내문과 어투 통일 | ❌ `아래로 스크롤` |

**Why:** 사용자가 이유를 명시한 적은 없지만 다섯 사례가 한 방향을 가리킵니다. 이 페이지는 **전 교인**이 보는 초대장이라(`docs/requirements.md`) 연령대가 넓고, "예쁜 장치"보다 바로 알아보는 것이 우선입니다. 또 핸드오프의 `radius: 0` 같은 토큰은 졸업장 **콘텐츠**의 시각 언어이지, 바텀시트·토스트처럼 **기능적 UI**에까지 기계적으로 적용할 규칙이 아니었습니다.

**How to apply:**

- 새 UI 요소는 먼저 **그 플랫폼의 관습대로** 만듭니다. 컨셉 각색은 색·서체·테두리 선에서 그칩니다.
- 장식을 하나 더 얹고 싶을 때는 넣지 말고 **먼저 제안**합니다.
- 문구는 은유나 문학적 표현보다 **동작을 그대로 말하는 쪽**으로.
- 핸드오프 토큰을 기능적 UI(시트·토스트·버튼)에 그대로 적용하지 않습니다.
