## 판단한 것

**1. SDK는 카드 모양을 바꾸지 않는다 — 썸네일이 선결 조건**

참고 레포의 `kakaoShare.ts`는 `sendDefault`(수동 카드 구성)가 아니라 **`sendScrap({ requestUrl })`** 을 씁니다. 카드의 제목·설명·이미지가 전부 페이지의 `og:*` 태그에서 나옵니다.

그런데 카카오톡은 링크를 그냥 붙여넣어도 OG를 긁어 카드를 만듭니다. 즉 **SDK로 얻는 건 "페이지를 떠나지 않고 채팅방을 골라 보내는 편의"이지 카드 품질이 아닙니다.** `public/icons/thumbnail.png`가 없으면(현재 404) 공유 기능이 있든 없든 이미지 없는 카드가 나갑니다. 이 사실을 `kakaoShare.ts` 헤더 주석과 `.env.example`에 명시해 뒀습니다.

참고로 참고 레포의 실측 운영 통계는 31일간 공유 API 호출 ~40회 / 공유 사용자 ~24명이고, 그중 개발 테스트 10건과 "나와의 채팅" 25%를 빼면 실질 재공유는 20건 남짓이었습니다. **큰 효과를 기대할 기능은 아닙니다.**

**2. `lucide-react`를 들이지 않고 인라인 SVG로**

참고 레포는 링크 아이콘에 `lucide-react`를 씁니다. 이 프로젝트는 런타임 의존성을 `react`/`react-dom` 두 개로 유지해 왔고, 아이콘 하나 때문에 패키지를 추가할 이유가 없어 인라인 SVG로 그렸습니다. **의존성은 그대로 2개입니다.**

**3. 공유 URL을 `og:url`에서 읽는다**

참고 레포는 컴포넌트에 `SHARE_URL` 상수를 박아 두어 `index.html`의 `og:url`과 이중 관리했습니다. 도메인이 바뀔 때 한쪽만 고치고 놓치기 쉬운 구조입니다.

여기서는 `canonicalUrl()`이 `meta[property="og:url"]`을 읽어 **`index.html`을 단일 출처**로 삼습니다. 태그가 없으면 `location.origin + pathname`으로 폴백합니다.

**4. JS키가 없어도 공유가 동작하도록 — 3단 폴백**

키 발급을 기다리며 기능을 놀리지 않도록 경로를 세 단계로 뒀습니다.

```
JS키 있음        → Kakao SDK sendScrap (참고 레포와 동일)
JS키 없음        → navigator.share (네이티브 공유 시트, 카카오톡 포함)
둘 다 불가       → 버튼 자체를 숨기고 링크 복사만 노출
```

세 번째가 중요합니다. 처음엔 실패 토스트를 띄우게 했는데, **눌러도 실패만 하는 막다른 버튼**이 되어 데스크톱 Firefox 등에서 나쁜 경험이 됩니다. `canShare`가 false면 버튼을 렌더하지 않습니다. 라벨도 경로에 맞춰 `카카오톡으로 공유` / `공유하기`로 갈립니다.

**5. FAB은 봉투가 걷힌 뒤에만**

참고 레포엔 봉투 개념이 없어 FAB이 항상 떠 있습니다. 여기서는 FAB의 `z-index`(40)가 봉투 오버레이(20)보다 높아, 게이트를 걸지 않으면 **봉투 위에 공유 버튼이 떠 버립니다.** `active` prop으로 막고, 0.6초 지연 후 페이드인해 표지가 자리를 잡은 뒤 조용히 나타나게 했습니다.

**6. 아이콘 파일 404 폴백**

`/icons/kakaotalk.png`는 아직 없습니다. `onError`로 인라인 말풍선 SVG로 교체합니다 — Testimony 영상이 쓰는 폴백 패턴과 같습니다. 파일을 넣으면 자동으로 그쪽이 쓰입니다.

**7. 디자인 각색**

본문은 핸드오프 토큰대로 `radius: 0`(각진 졸업장 톤)이지만, **바텀시트와 토스트만 둥글게** 두었습니다. 시트는 화면 아래에서 물리적으로 올라오는 UI라 각지면 화면에 붙어버린 느낌이 나서입니다.

처음엔 시트 상단에 Frame의 이중 금박 테두리 모티프를 얇은 가로선으로 넣었다가, 발주 측 피드백으로 제거했습니다 — 둥근 모서리와 만나니 떠 있는 선처럼 보였습니다. 지금은 상단 금박 테두리 하나만 남았습니다.

참고 레포는 Wave Layers 톤(글래스모피즘 `backdrop-filter`, Bebas Neue, 파란 계열)입니다. 졸업장 톤에 맞춰 바꿨습니다.

| | 참고 레포 | 이 프로젝트 |
|---|---|---|
| FAB | 글래스모피즘 원형 + 자체 화살표 | 종이 바탕 + 금박 테두리 원형(왁스 씰의 원형). 아이콘은 발주 측 제공 업로드 SVG, `fill=currentColor`로 톤 상속 |
| 시트 | `borderRadius: 18` + 흰 배경 | 종이 바탕 + 상단 금박 테두리. 라운딩 18px은 동일 |
| 라벨 | Bebas Neue `SHARE` | Cinzel Decorative `SHARE` (라틴 전용이라 서체 안 갈라짐) |
| 항목 | Pretendard 600 | 나눔명조 700 |
| 토스트 | `radius: 999` 알약 | 알약 동일, 색만 잉크/종이 톤 |

**8. `Esc`로 닫기 추가**

참고 레포엔 없습니다. 배경 탭·핸들 드래그만으로는 데스크톱에서 답답해 키보드 경로를 넣었습니다.

**9. 모션 감소 대응**

시트 슬라이드·배경 페이드·토스트 등장을 모두 `usePrefersReducedMotion`으로 껐습니다. 참고 레포는 이 컴포넌트에 대응이 없었습니다.
