# 2026-09-16 · 간증 영상 섹션을 초원별 10개 카드로 변경

> 단일 통합 영상 대신 초원별 영상 10개를 2열 × 5행으로 표시하고, 각 영상 아래 초원명을 배치했다.

## 한 일

- 사용자 제공 이미지(`KakaoTalk_20260915_094358116.png`)의 2열 배치를 적용했다. 이미지에는 8개가 있지만 요청한 총 10개에 맞춰 5행으로 구성했다.
- `G.video`를 `G.testimony.groups`로 교체했다. 초원별 고정 식별자·표시명·영상 데이터를 분리하고, 섹션 제목도 데이터 파일로 옮겼다.
- 기존 16:9 영상 슬롯과 금색 테두리·배경을 유지했다. 작은 카드에서는 준비 안내의 아이콘·글자·간격을 줄여 잘림을 방지했다.
- 각 카드의 진입 애니메이션에 봉투 개봉 후 활성화되는 `Reveal.active` 게이트를 유지했다.
- 영상 플레이어의 접근성 이름과 재생 집계 식별자를 초원별로 지정했다. `video_play.video` 값은 `testimony-1`부터 `testimony-10`까지다.
- `.env.example`, README, 요구사항에 초원별 이름·영상 연결 방법을 반영했다.

## 판단한 것

- 실제 초원명과 영상 파일 대응이 제시되지 않았으므로 이미지처럼 `초원 1` ~ `초원 10`으로 표시했다. 로컬의 영상 9개는 임의로 배정하지 않았다.
- 각 초원의 URL이 비어 있으면 네트워크 요청 없이 준비 안내를 표시한다. 연결한 영상의 재생 실패도 해당 카드 안에서 준비 안내로 처리한다.
- 초원별 URL과 포스터는 `VITE_TESTIMONY_<번호>_VIDEO_URL` / `VITE_TESTIMONY_<번호>_VIDEO_POSTER`로 지정한다. 표시명과 순서는 `graduation.ts`에서 수정하고, 집계용 번호는 이름이 바뀌어도 유지한다.
- 기존 단일 영상 환경 변수와 `/video/testimony.mp4` 자동 연결은 제거했다. 하나의 영상을 10개 초원에 중복 배정하지 않기 위해서다.
- 화면 폭이 좁아져도 2열을 유지하며, 내용이 화면 높이를 넘으면 기존 본문 스크롤로 이어서 본다. 새 라이브러리는 추가하지 않았다.
