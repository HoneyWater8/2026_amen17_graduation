# 2026-09-22 · 봉투 개봉 속도 복원

> 봉투가 열리는 속도는 원래대로 되돌리고, 열기가 끝난 후 첫 섹션으로 넘어가는 추가 대기만 줄인다.

## 한 일

- 사용자 요청에 따라 플랩 회전을 기존 850ms, 플랩이 카드 뒤로 넘어가는 지연을 420ms로 복원했다.
- 카드 상승을 기존 지연 350ms + 전환 1,050ms로 복원했다.
- 개봉 단계는 카드 상승이 끝나는 1,400ms에 종료하도록 맞췄다. 이전 작업의 700ms를 유지하면 카드가 올라오는 도중 봉투가 사라지므로 함께 조정했다.
- 오버레이의 추가 지연은 제거한 상태로 유지하고 300ms에 걸쳐 본문으로 전환한다. README와 UI 선호 메모리를 갱신했다.

## 판단한 것

- 앞선 첫 섹션 표시 시간 단축 요청과 이번 개봉 속도 복원 요청을 함께 반영했다. 봉투 자체의 원래 움직임을 보존하면서 끝난 뒤의 대기를 줄였다.
- 이전 작업 로그는 당시 결과를 기록한 것이므로 수정하지 않고 이 로그에 변경된 결정을 남긴다.

## 확인한 것

- `npm run build`, `npm run lint` 통과.
- 단축 이전 커밋 `76e938c`의 플랩·카드 전환 값과 일치함을 확인했다.
- 모바일 390×844 브라우저에서 진입 완료 후 클릭과 진입 도중 클릭을 확인했다. 봉투가 완전히 사라지는 시점은 약 1.77초, 첫 섹션이 완전히 보이는 시점은 약 2.2~2.3초였다. 스크롤 가능, 런타임 예외 없음.
