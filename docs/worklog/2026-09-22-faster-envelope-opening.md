# 2026-09-22 · 봉투 클릭 후 첫 섹션 표시 시간 단축

> 클릭 후 첫 섹션이 완전히 보이기까지 약 2.55초 걸리던 흐름을 약 1.5초로 줄였다.

## 한 일

- 개봉 단계 대기를 1,500ms에서 700ms로 줄이고, 오버레이 페이드의 추가 지연 550ms를 제거했다. 페이드 시간은 500ms에서 300ms로 변경했다.
- 플랩은 550ms, 카드 상승은 지연 100ms + 전환 700ms로 맞췄다. 개봉 중 플랩이 카드 뒤로 넘어가는 시점은 회전 시간의 중간을 유지했다.
- `Envelope`에 중복 하드코딩돼 있던 전환 값을 `MOTION` 토큰으로 연결하고 README의 시간 안내를 갱신했다.

## 판단한 것

- 사용자가 요청한 클릭 이후의 대기를 줄였다. 페이지 첫 진입 연출과 다른 섹션의 `Reveal` 속도는 유지했다.
- 본문의 `active` 게이트를 유지해 클릭 전에 애니메이션이 소진되지 않도록 했다. 700ms에 오버레이 페이드와 본문 표시가 함께 시작되고, 봉투는 약 1초에 사라진다.

## 확인한 것

- `npm run build`, `npm run lint` 통과.
- 로컬 빌드를 모바일 390×844 브라우저에서 확인했다. 100ms 간격 측정에서 봉투가 완전히 사라지는 시점은 약 1.04~1.15초, 본문 불투명도가 1에 도달하는 시점은 약 1.57초였다.
- 봉투 진입 완료 후 클릭과 진입 도중 클릭 모두 정상 표시·스크롤 가능. 런타임 예외 없음, 첫 섹션 화면 확인.

## 남긴 것

- 로컬 변경 상태이며 커밋·푸시는 수행하지 않았다. 배포 시에는 `main` 커밋·푸시에 따른 자동 배포를 사용한다.
