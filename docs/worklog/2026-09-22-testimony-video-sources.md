## 판단한 것

- 이미 변환해 둔 540p 경량본을 기존 재생기에 연결했다. 미수령 초원의 경로를 임의로 생성하지 않았다.
- 영상 원본과 재생본은 기존 방침대로 Git에서 제외한다. 로컬에서 재생되더라도 Git 푸시만으로 영상 파일이 배포되지는 않으며, 외부 업로드와 공개 URL 설정이 필요하다.
- 전체화면 고화질 전환은 아직 구현하지 않았다. 이번 변경은 수령한 영상 표시와 재생 연결이다.

## 확인한 것

- `npm run build`, `npm run lint`, `git diff --check` 통과.
- 빌드된 페이지에서 4개 영상의 초원명·경로·960×540 해상도·길이와 실제 재생을 확인했다. 재생 오류와 런타임 예외 없음.
- 모바일 320·390·460px에서 2열 × 5행, 영상 4개·준비 안내 6개, 가로 넘침 없음.
- 영상 요청을 차단했을 때 해당 카드가 준비 안내로 전환되는 것을 확인했다.
