# 2026-09-26 · 마지막 섹션 푸터 하단 배치

> 저작권과 제작자 문구를 마지막 섹션 맨 아래에 배치한다.

## 한 일

- 사용자의 추가 요청에 따라 마지막 섹션 아래 여백을 92px에서 24px로 줄였다.
- 저작권과 제작자 문구를 하나의 `footer`로 묶어 섹션 하단에 배치했다. 문구와 중앙 정렬은 유지한다.

## 판단한 것

- 공유 버튼 때문에 문구 전체를 위로 올리는 대신, 푸터 양옆에 버튼 공간을 확보했다. 좁은 화면에서는 줄바꿈해 문구와 버튼이 겹치지 않게 한다.
- 문서 흐름 안에 두므로 화면 높이가 낮거나 문구가 여러 줄이 되어도 본문과 겹치지 않고 스크롤할 수 있다.
- 앞선 고화질 전환·제작자 문구 변경은 `51bb074`로 main 푸시 및 자동 배포 완료. 이번 수정도 사용자가 진행 중인 커밋·푸시 작업에 추가한 요청으로 반영한다.

## 확인한 것

- TypeScript/Vite 빌드와 ESLint 통과.
- Chrome에서 320×568, 390×844, 460×900, 1024×768, 844×390 화면을 확인했다. 마지막 섹션 끝과 푸터 사이가 24px이며 공유 버튼과 겹침·가로 넘침·런타임 오류가 없다.
- 검증 기록은 Git 제외된 `assets/video-work/closing-footer-bottom-local.json`에 보관한다.
