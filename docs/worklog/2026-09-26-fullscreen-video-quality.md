# 2026-09-26 · 전체화면 고화질 전환

> 간증 10편과 감사 합본을 전체화면에서 고화질로 전환하고, 같은 재생 위치에서 경량본으로 복귀한다.

## 한 일

- `GradVideo.fullSrc`와 11개 `VITE_*_VIDEO_FULL_URL` 연결을 추가했다. 원격 경량본만 설정한 환경에서는 없는 로컬 고화질 주소를 요청하지 않고 기존 경량본을 유지한다.
- 공통 플레이어에 표준 전체화면 및 Safari 네이티브 영상 이벤트 처리를 연결했다. 같은 video 요소에서 소스를 바꾸므로 기본 컨트롤·접근성·음량 설정을 유지한다.
- 재생 위치, 재생/일시정지, 속도, 음량, 음소거를 보존한다. 빠른 왕복 전환 중에는 아직 로딩 중인 0초 대신 이전에 저장한 재생 위치를 이어받는다.
- 고화질 오류 및 15초 로딩 시간 초과 시 같은 위치의 경량본으로 복귀한다. 다른 영상이 재생되면 전환 완료 후 예약된 자동 재개도 취소한다.
- 변환 도구에 `hd.mp4` 생성을 추가했다. `full.mp4`의 해상도·프레임률·AAC 음성을 유지하면서 H.264 CRF 24 / medium으로 웹 전송용 압축을 적용한다. `--section hd`, `--hd-section testimony|graduation`으로 필요한 부분만 만들 수 있다.
- 고화질 11편을 변환·전체 구간 디코딩 검증한 뒤 기존 Vercel Blob에 업로드했다. Production/Preview의 고화질 URL 11개도 등록했다. 고화질 합계 731,514,520 B이며 기존 파일까지 포함한 저장소 전체는 989,065,457 B다.

## 판단한 것

- 준비된 `full.mp4` 11개 합계는 3,424,284,741 B다. 기존 경량본을 포함하면 Hobby 저장 공간 포함량 1GB를 넘으므로 원본·full은 보존하고 배포용 hd를 따로 만들기로 했다.
- 화면 진입 시 고화질을 미리 내려받지 않는다. 전체화면에 들어갈 때만 요청해 초기 데이터 사용량을 제한한다.
- HLS나 별도 플레이어 라이브러리는 필요하지 않아 기존 MP4와 네이티브 컨트롤을 유지했다. 소스 교체에는 짧은 버퍼링이 생길 수 있다.
- 브라우저 정책으로 `play()`가 거절되면 오류 화면으로 바꾸지 않고 같은 위치에서 사용자가 다시 재생할 수 있게 한다.
- 원격 URL은 공개 주소만 환경 변수에 넣는다. 인증 값과 영상 파일은 Git에서 제외하며 직접 Vercel 배포 명령은 사용하지 않는다.

## 확인한 것

- `npm test`: 비동기 이벤트 순서의 경합을 재현하는 자동 회귀 테스트 14개. 정상 왕복, 일시정지·종료 위치, 빠른 반복, 오류·시간 초과, 다른 영상 재생과 늦은 play 이벤트, Safari 이벤트, 잘못된 URL, 정리 후 늦은 이벤트와 재생 종료를 포함한다.
- 로컬 Chrome의 실제 전체화면에서 540p→1080p→540p 전환, 위치·속도·음량 보존, 빠른 왕복, 네트워크 요청 보류 중 다른 영상 재생, 고화질 요청 차단 시 복귀를 확인했다. 런타임 예외 없음.
- 고화질 요청 전에는 고화질 미디어를 선로딩하지 않도록 구현했다.
- TypeScript/Vite 빌드와 ESLint, 자동 테스트 14개가 통과했다.
- 공개 고화질 URL 11개 모두 `HEAD 200`, `video/mp4`, 정확한 파일 크기, `Range 206` 및 첫·끝 1KB의 로컬 파일 일치를 확인했다. 감사 합본은 업로드 직후 한 차례 Range 전체 크기 헤더가 달랐지만, 후속 확인에서는 정상 응답과 파일 일치를 확인했다.
- 공개 Blob URL을 연결한 프로덕션 빌드를 로컬 Chrome에서 확인했다. 간증 10편과 감사 합본 모두 65% 지점에서 전체화면 진입 후 1080p·720p·1440p로 전환하고, 재생 후 종료하면 같은 위치의 540p로 복귀했다. 고화질 선로딩·런타임 예외가 없었으며 재생 상태·속도·음량·음소거를 유지했다.
- 검증 기록은 Git 제외된 `assets/video-work/fullscreen-browser-cases.json`, `fullscreen-all-blob.json`, `blob-hd-deployment.json`과 변환 보고서에 보관한다.
