# 2026-09-29 · 졸업자 명단 4명 추가

> 사용자에게 추가로 전달받은 네 이름을 공개 명단에 반영했다.

## 한 일

- `박현수`, `강효림`, `고윤호`, `김반석`을 기존 128명 명단에 추가해 총 132명으로 만들었다.
- 새 이름의 `반`, `효`가 기존 부분 폰트에 없어 캐시된 원본으로 WOFF2 3종과 생성 기록을 다시 만들었다.
- README와 요구사항 문서의 명단 현황을 갱신했다.

## 판단한 것

- 기존 명단의 이름 오름차순 배열을 유지했다. 새 이름은 별도 그룹으로 분리하지 않았다.
- 원본 엑셀은 최초 128명의 수령 자료로 보존하고, 이번 네 이름은 사용자 추가 전달분으로 구분해 기록했다.

## 확인한 것

- 명단 132명 모두 고유하고 이름 오름차순이며, 전달받은 네 이름이 각각 한 번씩 포함된 것을 확인했다.
- 폰트 글자 검사에서 313개 소스 글자를 확인했고, 프런트엔드 빌드와 린트가 통과했다.
